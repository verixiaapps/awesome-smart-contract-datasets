## Solo Códigos

- [solidity-dataset](https://huggingface.co/datasets/seyyedaliayati/solidity-dataset) - Este conjunto de datos se recopila de repositorios públicos de GitHub escritos en el lenguaje de programación Solidity.

- [smart-contract-fiesta](https://huggingface.co/datasets/Zellic/smart-contract-fiesta) - Zellic hace público un conjunto de datos del código fuente de contratos inteligentes conocidos de la red principal de Ethereum.

- [smartbugs-wild](https://github.com/smartbugs/smartbugs-wild) - Este repositorio contiene 47,398 contratos inteligentes extraídos de la red Ethereum.

- [DISL](https://huggingface.co/datasets/ASSERT-KTH/DISL) - 514,506 archivos únicos de Solidity que han sido desplegados en la red principal de Ethereum.



## Con Vulnerabilidades o Errores

- [HuangGai](https://github.com/xf97/HuangGai) - HuangGai es un marco de inyección de errores para contratos inteligentes de Ethereum, puede inyectar 20 tipos de errores en contratos inteligentes de Solidity.

- [JiuZhou](https://github.com/xf97/JiuZhou) - JiuZhou es un conjunto de datos de contratos inteligentes de Ethereum con errores.

- [ScrawlD](https://github.com/sujeetc/ScrawlD) - Un conjunto de datos de contratos inteligentes de Ethereum del mundo real etiquetados con vulnerabilidades.

- [Smart-Contract-Benchmark-Suites](https://github.com/renardbebe/Smart-Contract-Benchmark-Suites) - Evaluación empírica de las pruebas de contratos inteligentes: ¿cuál es la mejor opción?

- [Smart-Contract-Dataset](https://github.com/Messi-Q/Smart-Contract-Dataset) - Conjuntos de datos para evaluar herramientas de análisis de seguridad de contratos inteligentes.

- [VeriSmart-benchmarks](https://github.com/kupl/VeriSmart-benchmarks) - VeriSmart es un analizador de seguridad para contratos inteligentes de Ethereum escritos en Solidity. Este repositorio contiene el conjunto de datos que utilizamos para los experimentos en nuestro artículo.

- [DAppSCAN](https://github.com/InPlusLab/DAppSCAN) - Creación de conjuntos de datos a gran escala para debilidades de contratos inteligentes en proyectos DApp.

- [smartbugs-curated](https://github.com/smartbugs/smartbugs-curated) - SB Curated: Un conjunto de datos curado de contratos inteligentes de Solidity vulnerables.

- [SmartScan-Dataset](https://github.com/NoamaSamreen93/SmartScan-Dataset) - Este repositorio presenta conjuntos de datos y resultados de análisis empírico que utilizan técnicas de detección de clones de código para identificar vulnerabilidades y sus variaciones en contratos inteligentes.

- [ReentrancyStudy-Data](https://github.com/InPlusLab/ReentrancyStudy-Data) - ReentrancyStudy-Data es un conjunto de datos a gran escala de la vulnerabilidad de reentrada en contratos inteligentes, construido a partir de 230,548 contratos inteligentes de código abierto de Etherscan.

- [AFT2020/dataset](https://github.com/AFT2020/dataset) - (NO VERIFICADO) Este repositorio contiene un conjunto de datos de vulnerabilidades de contratos inteligentes que se utiliza en experimentos de aprendizaje automático.

- [Web3Bugs](https://github.com/ZhangZhuoSJTU/Web3Bugs) - Este proyecto busca proporcionar un recurso valioso para desarrolladores Web3 y analistas de seguridad, facilitando su comprensión de errores explotables en contratos inteligentes.

- [smart-contract-vulndb](https://github.com/tintinweb/smart-contract-vulndb) - Un conjunto de datos abierto de problemas públicos de contratos inteligentes agregados de varios informes de auditoría.

- [Reviews](https://zenodo.org/record/6762730#.ZDKVkXbP1D9) - Una revisión de conjuntos de datos de vulnerabilidades de contratos inteligentes.

- [reentrancy_solidity_function](https://huggingface.co/datasets/nguyenminh871/reentrancy_solidity_function)

- [multi_class_solidity_function_vulnerabilty](https://huggingface.co/datasets/nguyenminh871/multi_class_solidity_function_vulnerabilty)

- [solidity-defi-vulnerabilities](https://huggingface.co/datasets/seyyedaliayati/solidity-defi-vulnerabilities) - Contiene datos relacionados con varios escenarios de ataque y vulnerabilidades de finanzas descentralizadas (DeFi), incluyendo información sobre explicaciones de ataques, casos de prueba, fechas, conteos de tokens, interfaces, valores perdidos, títulos de ataques y rutas de contratos.

- [slither-audited-smart-contracts](https://huggingface.co/datasets/mwritescode/slither-audited-smart-contracts) - Este conjunto de datos contiene código fuente y bytecode desplegado para contratos inteligentes de Solidity que han sido verificados en Etherscan.io, junto con una clasificación de sus vulnerabilidades según el marco de análisis estático Slither.

- [SolidiFI-benchmark](https://github.com/DependableSystemsLab/SolidiFI-benchmark) - Repositorio de benchmarks para evaluar herramientas de análisis de contratos inteligentes de Solidity.

- [A_benchmark_dataset_of_Solidity_smart_contracts](https://zenodo.org/records/7744053) - Un conjunto de datos de referencia contiene 4,364 contratos inteligentes de Solidity del mundo real, etiquetados manualmente con diez tipos de vulnerabilidades.

- [Vulnerable_Verified_Smart_Contracts](https://figshare.com/articles/dataset/Vulnerable_Verified_Smart_Contracts/21990287) - Conjunto de datos de contratos inteligentes de Ethereum vulnerables reales.

- [DeFiHackLabs](https://github.com/SunWeb3Sec/DeFiHackLabs) - Reproducir incidentes de hackeo en DeFi utilizando Foundry. POCs de explotación de DeFi del mundo real y códigos vulnerables (dentro del POC como comentario).

- [smart-contract-vulnerability-dataset](https://github.com/imranpollob/smart-contract-vulnerability-dataset) - Conjunto de datos etiquetado para la vulnerabilidad de manipulación de tiempo en contratos inteligentes de Ethereum.
